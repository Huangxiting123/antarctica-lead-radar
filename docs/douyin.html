抖音授权接入说明

适用于全域媒介情报雷达的抖音开放平台功能

本功能仅处理抖音账号持有人主动授权范围内的数据，不用于抓取任意账号、绕过平台限制或自动群发营销评论。

一、功能用途

用户在桌面软件中连接自己有权管理的抖音账号后，可读取该授权账号允许访问的视频列表及相关评论，用于内容运营复盘、受众需求研究和人工线索整理。

二、所需权限

video.list

用于获取已授权抖音账号在授权范围内的视频列表、视频标题、公开链接及 Item ID，以便用户选择需要分析的视频。

video.comment

用于读取和管理已授权账号自有视频的评论，帮助账号运营者筛选反馈、整理问题与进行人工回复。实际能力以抖音开放平台审核结果及接口文档为准。

三、授权流程

  1. 用户在本产品中主动点击“连接抖音账号”。
  2. 浏览器跳转至抖音官方授权页面，由用户确认授权范围。
  3. 安全后端使用一次性授权码换取访问令牌，Client Secret 不会写入前端页面。
  4. 本产品在授权有效期内按用户主动操作调用官方接口。
  5. 用户可在抖音授权管理中撤回授权，并删除本地保存的记录。

四、数据字段

在获得对应权限后，本功能可能处理：授权账号 Open ID、视频 Item ID、视频标题和分享链接，以及评论者公开昵称、公开标识、评论内容和评论时间。具体字段由开放平台实际返回内容决定。

五、自动化边界

本产品不自动向陌生用户批量发送评论或私信。关键词和意向标签只用于本地辅助筛选，任何回复或后续联系均须由使用者人工判断，并遵守抖音社区规范。

六、支持与撤回

如对授权用途、删除记录或技术接入有疑问，请联系 huang19228163591@icloud.com。您也可以直接在抖音相关授权管理页面撤回授权。
